# ЖК «Белая лилия» — лендинг

Одностраничный сайт жилого комплекса «Белая лилия» (Заволжский район Ярославля,
застройщик ООО «СЗ «ПОБЕДОНОСЦЕВ ГРУПП») под запуск контекстной рекламы.

## Что внутри

- `index.html` — вся страница: разметка, стили и скрипты в одном файле, без сборки и зависимостей.
- `img/` — визуализации проекта, логотип и иконки в WebP.
- `robots.txt` — индексация закрыта.

## Как открыть

Достаточно открыть `index.html` в браузере — внешних зависимостей нет,
кроме шрифтов Google Fonts (Playfair Display и Inter).

## Перед публикацией на домене

1. **Обработчик заявок.** В `index.html` найдите `var ENDPOINT = null` и подставьте
   URL своей CRM или почтового скрипта. Пока значение `null`, заявка пишется в консоль.
2. **Яндекс.Метрика.** Вставьте счётчик и задайте `window.YM_ID` — цель `lead`
   вызывается при успешной отправке формы.
3. **Индексация.** Если сайт должен попадать в поиск, уберите `<meta name="robots">`
   из `index.html` и правило `Disallow` из `robots.txt`.
4. **Мета-слой.** Проверьте `og:image` и канонический адрес — сейчас они относительные.

## Особенности вёрстки

- Mobile-first, проверено на 320 / 430 / 500 / 800 / 1440 px, горизонтального скролла нет.
- Контраст текста 14,4:1, вторичного 5,4:1, акцента 5,6:1.
- Анимации (панорама героя, проявление блоков, бегущая строка, параллакс) отключаются
  при системной настройке «уменьшить движение»; без JavaScript страница читается полностью.
- Форма: видимые подписи, маска телефона, проверка на blur, выбор времени звонка,
  состояние отправки и ошибки, `aria-live` для статуса.

## Данные проекта

Цены, планировки, точный адрес и сроки на момент вёрстки не объявлены — на странице
их нет намеренно. Все факты (этажность, потолки 3 и 3,3 м, газовое отопление,
закрытая территория) взяты из анонса застройщика.
